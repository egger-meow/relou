## 同系判定

同校且相同系所群組才算同系，跨學位不影響：例如陽明交大運輸與物流管理學系學士、交通運輸碩士、物流管理碩士歸同系。用固定且可稽核的完整名稱規則產生群組：同一學系的碩博士班／專班歸本系，完全相同名稱的系所跨學位同群組；獨立研究所不因學門相近或行政隸屬同一學院就合併。同名但不同學校不算同系。

選「只限同校同系」或「避開同校同系」皆為雙向硬條件，不是加減分。兩人限制衝突就不能配對。早期配對與期末配對共用同一檢查。新提交必須有正確學校、學位、系所組合，後端從版本目錄產生群組並凍結到私人答案 JSON，不接受客戶端自傳群組。舊資料若缺系所，不能滿足任何同系／不同系硬限制；不猜測、不從信箱推斷。校系不出現在公開統計或結果信。
